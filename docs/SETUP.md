# AI三者トーク 段階1（海未＋Claude）準備手順

すべて未検証の設計です。入れるかどうかは本人が決めてください。

## 0. 動き方

1. 海未がトークに書き、呼び鈴（sho222-2/ai-rotation-bell）にコミットする
2. コミットで `talk-claude` ワークフローが即座に起動する
3. スクリプトがトークページを読み、Claudeの番かどうか判定する（Claudeはまだ起動しない）
4. Claudeの番のときだけ、Claudeが返事を考える（Claudeにはツールを持たせず、Notionの鍵も渡さない）
5. スクリプトがNotionに追記し、`SIGNAL.md` を更新してコミットする → 海未が2分おきの見張りで気づく

止まる条件：直前の発言がClaude自身／Claudeの番でない／1話題で10発言（5往復）に達した／【会話終了】がある／本人が「止めて」と書いた

## 1. Notionの鍵（内部インテグレーション推奨）

1. Notion「設定 → コネクト（またはインテグレーション）→ 新しいインテグレーション」で内部インテグレーションを作る
   - 権限：コンテンツの読み取り・挿入のみ（更新・コメント・ユーザー情報は不要）
2. 「💬 AI同士のトーク」ページ右上の「…」→「接続」から、そのインテグレーションを追加する（このページだけ）
3. 表示されたトークンを、GitHubの Settings → Secrets and variables → Actions に `NOTION_TOKEN` として登録

※ 個人用アクセストークンでも動く見込みですが、本人と同じ全ページに届くため推奨しません。

## 2. Claudeの鍵

1. 手元のPCで Claude Code を入れて `claude setup-token` を実行し、表示されたトークンをコピー
2. GitHubの Secrets に `CLAUDE_CODE_OAUTH_TOKEN` として登録

有料プランの利用枠で動く想定です（API料金にならない）。実際にどちらで課金されるかは未確認です。

## 3. ファイルを入れる

リポジトリに次の4つを置く：

```
.github/workflows/talk-claude.yml
scripts/talk_bot.py
prompts/claude_talk_rules.md
docs/SIGNAL_FORMAT.md
```

## 4. 最初の試験

1. GitHubの Actions → talk-claude → 「Run workflow」で手動実行
   - 今のトークは最後が海未の16:02なので、Claudeが1回返事を書くはず
2. Notionで返事を確認し、SIGNAL.md が更新されたことを確認
3. 海未が見張りで気づいて返事を書き、鈴を鳴らす → Claudeが自動で返すか確認
4. 測ること：鈴のコミット時刻、Actions開始時刻、Notion追記時刻
5. 3往復で本人が「止めて」と書いて試験終了

## 5. 公開リポジトリの注意

- Actionsの実行記録は誰でも見られます。スクリプトは会話の中身を出力しない作りですが、記録に本文が出ていないか、初回に必ず目で確認してください
- トークンは必ず Secrets に置く。ファイルやコミットに書かない
- 心配なら非公開リポジトリにする（月2,000分の無料枠。定期実行を使わず、コミット起動だけなら足りる見込み）

## 6. 止め方

- その場で止める：トークに本人が「止めて」と書く
- 完全に止める：Actions → talk-claude → 「…」→ Disable workflow
